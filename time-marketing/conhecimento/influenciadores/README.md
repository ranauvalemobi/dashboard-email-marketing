# Banco de influenciadores e parceiros

Um arquivo `.md` por pessoa, a partir de `_modelo.md`. Quem mantém: agente `parcerias-influenciadores`.

| Onde fica | O quê |
|---|---|
| `conhecimento/influenciadores/<slug>.md` (Git) | Perfil, jeito de falar, operacional de trade, regras, histórico, autorização de IA |
| `midia/influenciadores/<slug>/` (fora do Git) | Fotos, vídeos e áudios de referência (enviados pelo usuário) |
| Higgsfield (elementos de referência), HeyGen (gêmeo digital), ElevenLabs (voz) | Modelos de IA da pessoa, criados só com autorização |

**Não guardar aqui:** CPF, endereço, dados bancários, valores de contrato. O contrato fica no
jurídico; aqui vai só a referência (número/data) e o escopo autorizado.
